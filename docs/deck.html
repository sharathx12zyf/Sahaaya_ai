Sahaaya AI

A voice AI agent that answers every customer call in their own language, checks the business's real data, and gets the job done. It books the slot, fixes the KYC, or raises the ticket.

For small shops to large companies. Callers need no app and no internet, just their voice.

English · Kannada · Hindi · Telugu · Kanglish · Hinglish

Scaler × Wispr Flow "India Runs on Voice" hackathon · Round 2 prototype

1

The problem

  • Small businesses miss calls every day. A phone repair shop owner is busy with customers, has no receptionist, and nobody answers after hours. Every missed call is a lost customer.
  • Customer care speaks the wrong language. "Press 1 for English" fails a Kannada-speaking elder or a Telugu-speaking worker. Most callers would rather speak their own language than type in an app.
  • Simple problems take days. "Why is my order on hold?" → "KYC pending" → nobody tells the customer the PAN photo was blurry. Support staff must open dashboards, search and explain every single time.
  • Big call centres are costly, and they still can't cover every Indian language 24×7.
2

The solution: one voice agent for any business, two ways to use it

📞 Service Center

For any small business with no software: repair shop, kirana store, clinic, salon, restaurant or custom. The owner sets it up by talking: "1-hour slots, 24/7, take name, mobile and problem, quotation after checking".

"ನನ್ನ phone screen ಒಡೆದಿದೆ, ನಾಳೆ ಬರಬಹುದಾ?" ("My screen broke, can I come tomorrow?")
→ tells the price → checks the owner's schedule → offers 3 free slots → reads back the details → books Sat 11:00–11:30 → the booking appears on the owner's dashboard.

Also answers "is my phone ready?" from the repair list.

🔗 Dashboard Connect

For companies that already have a dashboard (API), or just a Google Sheet.

"मेरा order hold पर क्यों है?" ("Why is my order on hold?")
→ finds the caller's account → KYC pending, documents fine → "Shall I re-check?" → re-runs KYC on the company dashboard → order released.
Blurry photo? → sends the upload link and guides step by step.

3

Why voice comes first

  • Callers just speak, in their own language or mixed. No app, no reading, no typing. It also works for elders and for people who can't read English.
  • Owners set up the agent by talking to it. It asks follow-up questions, then they press "Demo call" to test it.
  • Owners teach the agent by speaking, in any language, like explaining to a new employee:
    "ಯಾರಾದರೂ KYC ಬಗ್ಗೆ ಕೇಳಿದರೆ, documents ಸರಿ ಇದ್ದರೆ recheck ಮಾಡಿ, photo blurry ಇದ್ದರೆ upload link ಕಳುಹಿಸಿ."
    ("If someone asks about KYC: if the documents are fine, re-check; if the photo is blurry, send the upload link.")
    → Sahaaya turns this into clear rules, reads them back in Kannada, and uses them after the owner approves.
  • Feels like a person: hands-free talking, the caller can interrupt, it says "ಒಂದು ನಿಮಿಷ" (one moment) instantly while it checks, and it keeps answers short.
4

How it works

🎤 Caller speaks (browser mic today; phone line next)
→ Sarvam Saarika speech-to-text, with automatic language detection
→ Agent brain: Sarvam-105B, with automatic backup to NVIDIA Nemotron. It uses tools:
   • Service Center: free slots, book, cancel, repair status, tickets
   • Dashboard Connect: tools generated automatically from the company's API description (OpenAPI)
→ Sarvam Bulbul natural Indian voice, first sentence first
→ Owner's dashboard updates live: bookings, tickets, actions, call transcripts

Built with FastAPI, SQLite and a plain web front-end. One command: docker compose up. It starts without keys and shows "key not set".

5

Accuracy and safety, enforced in code

RiskWhat Sahaaya does
Making things upAnswers only from records and the owner's info. A ready calendar is provided, so it never does date maths. It never promises new dates
Someone else's dataRecords that don't match the caller's number are withheld by the server unless the caller verifies with the last 4 digits. Changes run only on the caller's own records
Wrong actionReading is allowed, changes need the caller's "yes", deleting is blocked. The owner controls each action
Wrong languageA reply in the wrong script or with mixed scripts is regenerated
Noise or mishearingAsks again, reads numbers back, and after 3 tries creates a callback ticket
Service downAutomatic backup AI. A dashboard error leads to an apology and a ticket, never silence. Phone numbers are masked in logs and never spoken

Measured: 36 test conversations in 4 languages + mixed speech: 94% (text). An earlier run with real speech plus background noise scored 82%. Most remaining misses were the automatic grader being strict. No data leaks.

8

Launch plan: first users and growth

  • Month 1 — pilot with 20 shops in Karnataka (repair shops and clinics in Mysuru and Bengaluru). We set it up for them in person, for free, and measure missed calls, bookings made and language accuracy every week.
  • Month 2–3 — real phone numbers: call forwarding from the shop's own number to a Sahaaya number. Daily WhatsApp summary to the owner ("14 calls answered, 3 bookings").
  • Month 3–6 — first company integrations: fintech and e-commerce apps with KYC and order dashboards. Start read-only, then allow actions once the owner trusts it.
  • Growth: owner referrals, local trader associations, mobile shop resellers who set it up, and short demo videos in regional languages.
  • Pricing: free trial, then about ₹999/month for small shops (number + minutes) and custom plans for companies.
